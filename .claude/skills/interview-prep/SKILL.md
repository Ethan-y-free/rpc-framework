# 面试八股准备（实习冲刺）

## 触发条件

用户说"面试准备"、"八股"、"模拟面试"、"复习八股"等相关指令时使用。

## 执行流程

1. **确认范围**：项目深挖（EventLoop / TimerQueue / TcpServer）还是通用八股（C++ / 网络 / OS）
2. **出题**：一次 3-5 题，按 P0 > P1 优先级出
3. **用户作答** → 我点评：对错判断 + 深度补充 + 面试官视角（为什么问这个、期望听到什么）
4. **沉淀**：Q&A 追加到 `笔记-仿muduo网络库.txt`（面试前复习用）

## 优先级清单

### 🔴 P0 必背（面试 80% 问题来源）
- **C++**：虚函数/虚表/多态、shared_ptr/unique_ptr/weak_ptr 原理、右值引用/移动语义/完美转发、STL 容器底层（vector 扩容/map 红黑树/unordered_map）、RAII
- **网络**：TCP 三次握手/四次挥手状态迁移、拥塞控制/滑动窗口/TIME_WAIT、HTTP/1.1 vs 2、epoll LT/ET、epoll vs select/poll
- **OS**：进程 vs 线程/上下文切换、虚拟内存/分页/缺页中断、死锁四必要条件、互斥/自旋/读写锁/条件变量

### 🟡 P1 重要
- MySQL（B+树索引/MVCC/隔离级别/SQL优化）、Redis（5种数据结构底层/RDB/AOF/分布式锁）、C++11-17 新特性、设计模式（单例/工厂/观察者/策略）

### 🟢 P2 加分
- mmap/零拷贝/sendfile、io_uring、Docker、网络库/RPC 设计决策对比

## 沉淀规范

- 每轮 Q&A 追加到笔记，标注日期 + 编号
- 答错的题重点标记 🔴，下次复习先过这些
- 项目深挖问题走 `design-review` skill 的设计文档
